# TAB 名单限时跟踪

适用构建：`4.0.0-multisource.12-tab-diagnostic`，Fabric Minecraft 1.20.4。

诊断构建只包含取证功能，保留原有 TAB 行为。Exordium 的兼容绕过补丁和 `.13` 实验包已按用户要求撤回，详见 [根因与处理记录](TAB_SKIN_FINDINGS.zh-CN.md)。跟踪默认关闭；启用跟踪只观察包，不补发名单，不修改身份、认证或隐身状态。

## 复现一次并收集结果

1. 关闭服务器，备份旧 EasyAuth jar，将诊断 jar 放入 `mods` 并移出旧 jar，然后启动。不能同时加载两份 EasyAuth。
2. 在服务器控制台输入 `auth tab trace 120`。游戏内管理员使用 `/auth tab trace 120`。
3. 在两分钟内，让受影响的正版、MUA、离线客户端分别重新连接；离线账号完成登录。按 TAB 复现缺人，记录哪个视角看不到谁。若客户端也装了同一诊断 jar，在出现问题后执行 `/eatabdebug`，保存客户端快照。
4. 控制台执行 `auth tab status`，再执行 `auth tab stop`。保留这次服务端 `logs/latest.log` 以及受影响客户端自己的日志；多客户端应使用各自的游戏目录，避免同时覆盖同一个日志。

三个命令均要求 EasyAuth 管理员根权限和 `easyauth.commands.auth.getPlayerInfo`（默认 OP 等级 3）。跟踪时间只能为 1–300 秒，自动到期，最多记录 2000 条观察事件、128 个连接；手动停止后仍能查看已捕获状态。

## 如何读记录

日志前缀为 `[tab-debug]`，记录 viewer、target UUID、每次连接编号、动作、listed 布尔值、已观察的档案数与列出人数。显示名更新还记录 null／空白／非空分类、长度和有界文本。不会输出 IP、密码、会话令牌或完整纹理载荷。

- `stage=queued`：包已进入该连接的发送入口。
- `stage=encoded`：从 Minecraft 编码器输出缓冲区的独立视图重新解码得到的实际字段，位于加密／压缩／套接字传输之前；**不是客户端已接收的确认**。若观察本身无法解码，会明确输出 `encoding_observation_failed`，此时统计可能不完整。
- `ADD_PLAYER`：初始化该 UUID 的档案；`UPDATE_LISTED listed=true`：应列入 TAB；`listed=false`：从 TAB 隐藏；`action=REMOVE`：移除档案。
- `known_before=false`：本次跟踪尚未见过对应初始化。若跟踪是在玩家上线后才开启，不能据此判定漏包，所以需要在开启后重新连接。
- `history=not-observed`：该连接在本次跟踪中尚未产生可观察事件，不代表名单为空。

收到完整初始化并编码之后仍缺人的情况，需要进一步对照该客户端；缺少初始化、被取消或后续移除的情况，可沿服务端记录继续追查。状态统计仅代表跟踪期间观察到的内容，不是从客户端读取的真实列表。

## 验证范围

运行时测试通过真实 Connection、Netty EmbeddedChannel、Minecraft PacketEncoder 验证两个阶段的记录、移除、停止跟踪及输出包保持不变。另有编码对象与实际字节不一致的回归，确认按输出字节记录且不改变缓冲区索引。完整入服测试覆盖正版 v4、MUA v7 和标准离线 v3 UUID；会等待玩家实际加入世界后再检查三 tick，VMP 同版本组合也通过了这项检查。

部分现场模组组合测试中的旧认证夹具不具备 Krypton 所需的真实加密通道，因此该组合不是全部测试通过。不能把基础测试或选定模组测试当作现场全部 170 个模组加图形客户端验收。

## 客户端只读快照

同一个 jar 安装在 Fabric 1.20.4 客户端后，提供本地命令 `/eatabdebug`，不需要服务器管理员权限，也不会发送查询或修改服务器名单。每次手动执行只记录一份 `[tab-client-debug]` 快照，没有后台持续跟踪。

快照同时写入独立的 `logs/easyauth-tab-<玩家UUID>-<随机后缀>.log`，避免多个客户端共用游戏目录时相互覆盖 `latest.log`。命令会显示保存位置；独立文件写入失败时仍保留普通日志输出。

快照包含客户端持有的玩家档案、listed 集合、UUID 与名字、显示名是否为 null／空白、原版名称格式化结果、队伍前后缀、模式与延迟。还会检查 listed 中的对象是否与 UUID 映射指向同一个对象，用于识别陈旧列表条目。每类最多记录 256 项，每个文本最多 256 字符。只观察客户端已有的数据，不读取密码、令牌或纹理载荷。

命令通过编译及分发包检查，但尚未在用户的图形客户端中执行。`vanilla_name` 是原版格式化得到的文本，不是最终屏幕像素；它不能单独证明颜色、字体或第三方渲染缓存正常。
